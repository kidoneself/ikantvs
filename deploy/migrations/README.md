# 数据库迁移说明

| 目录 | 用途 |
|------|------|
| [`../init/`](../init/) | **新装空库**：一份最终态 schema + 演示种子（`docker-entrypoint-initdb.d`） |
| 本目录 `V001`… | **已有库增量**：线上演进历史；只追加，不改旧文件 |

- 别人/本地第一次起库 → 用 `init/`，不要重放本目录 55 个历史文件。
- 你自己的生产库已经跑过 V001–V055 → 继续在这里加 `V056__xxx.sql`，并同步把变更合并进 `../init/01_schema.sql`。
