# 部署架构

> 开源推荐：**宝塔管域名/证书 + Docker 跑业务**。无面板海外机可用 Caddy 单机。

## 1. 宝塔 + Docker（推荐）

详见 **[宝塔部署.md](宝塔部署.md)**。

```
用户 → 宝塔 Nginx（80/443 + SSL）
         ├── /     → 127.0.0.1:3080（web）
         └── /api  → 127.0.0.1:3088（backend）
后台 → http://服务器IP:3081（admin，容器内已反代 /api）
```

```bash
cd ikantvs/deploy
./deploy-baota.sh init   # 编辑 .env.baota
./deploy-baota.sh up
# 再到宝塔添加站点并反代
```

## 2. 海外单机 + Caddy（无宝塔）

一台 VPS，Caddy 自动 HTTPS；后台 `:8080`。

```bash
cd ikantvs/deploy
./deploy-single.sh init
# 编辑 SITE_DOMAIN / ACME_EMAIL / 密码 / JWT
./deploy-single.sh up
```

文件：`docker-compose.single.yml`、`Caddyfile.single`、`.env.single.example`。

## 数据模式

| 模式 | 说明 |
|------|------|
| 夸克热榜灌库（默认） | 启动/定时同步进 media |
| pansou 搜链 | 点片名找资源 |
| TMDB（可选） | 填 Key 后补录更全 |
