# 宝塔面板部署（开源推荐）

> 域名、SSL 用宝塔；业务用 Docker Compose。**不占用 80/443**，不会和宝塔 Nginx 抢端口。

## 你需要什么

| 项 | 说明 |
|----|------|
| 一台服务器 | 建议 **2 核 4G+**（开 pansou 更吃内存） |
| 宝塔面板 | 已安装，能添加网站、申请证书 |
| 一个域名 | A 记录指到服务器 IP |
| Docker | 宝塔「软件商店」安装 **Docker**（或 Docker 管理器） |

## 1. 安装 Docker

宝塔 → **软件商店** → 搜索 Docker → 安装。  
装好后终端执行应能看到版本：

```bash
docker -v && docker compose version
```

## 2. 拉取代码并启动容器

```bash
# 建议目录，也可放你习惯的路径
cd /www/wwwroot
git clone https://github.com/kidoneself/ikantvs.git
cd ikantvs/deploy

chmod +x deploy-baota.sh
./deploy-baota.sh init
```

编辑 `.env.baota`（必改）：

```bash
MYSQL_ROOT_PASSWORD=...
DB_PASSWORD=...
JWT_SECRET=...          # openssl rand -base64 48
CORS_ALLOWED_ORIGINS=https://你的域名,https://www.你的域名
```

内存紧（&lt;4G）可先关 pansou：`ENABLE_PANSOU=false`。

启动：

```bash
./deploy-baota.sh up
```

本机端口（给宝塔反代用）：

| 端口 | 用途 |
|------|------|
| `127.0.0.1:3080` | 前台 |
| `127.0.0.1:3088` | API |
| `服务器IP:3081` | 管理后台（需防火墙放行） |

自检：

```bash
curl -sS http://127.0.0.1:3088/api/health
```

## 3. 宝塔添加网站 + 反代

1. 宝塔 → **网站** → **添加站点**  
   - 域名填你的域名（如 `example.com`）  
   - PHP 选「纯静态」即可（实际走反代，不跑 PHP）

2. 站点设置 → **反向代理** → 添加：  
   - 代理名称：任意，如 `ikantvs`  
   - 目标 URL：`http://127.0.0.1:3080`  
   - 发送域名：`$host`  
   - 开启即可

3. **还要让 `/api` 打到后端**（重要）  
   站点设置 → **配置文件**，在 `server { ... }` 里、其它 `location` 之前加入：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:3088;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 120s;
    client_max_body_size 50m;
}
```

保存并重载 Nginx。

4. 站点设置 → **SSL** → Let's Encrypt 申请证书 → 开启「强制 HTTPS」。

5. 浏览器打开 `https://你的域名`，再访问 `https://你的域名/api/health` 应返回正常 JSON。

## 4. 管理后台

浏览器打开：

```text
http://服务器IP:3081
```

默认账号 `admin` / `admin123`（**务必改密**）。

宝塔 **安全** / 云厂商防火墙放行 **3081**。

可选：再建一个 `admin.你的域名` 站点，反代到 `http://127.0.0.1:3081`，并同样给 `/api/` 指到 `3088`（或依赖 admin 容器内已反代 `/api`）。

## 5. 常用命令

```bash
cd /www/wwwroot/ikantvs/deploy
./deploy-baota.sh status
./deploy-baota.sh logs backend
./deploy-baota.sh down          # 停掉容器
./deploy-baota.sh up            # 改配置/更新代码后重新 up
```

更新代码：

```bash
cd /www/wwwroot/ikantvs
git pull
cd deploy && ./deploy-baota.sh up
```

## 常见问题

| 现象 | 处理 |
|------|------|
| 宝塔打不开 / 证书失败 | 确认 80/443 给**宝塔**，本项目 compose **不要**再映射 80/443 |
| 前台有、接口 404/502 | 检查站点配置里是否加了 `location /api/` 到 `3088` |
| 跨域报错 | `.env.baota` 的 `CORS_ALLOWED_ORIGINS` 必须是 `https://你的域名`，改完后 `./deploy-baota.sh up` |
| 内存不够 | `ENABLE_PANSOU=false` 后重新 up |
| 后台打不开 | 放行 3081；本机先 `curl -I http://127.0.0.1:3081` |

## 和「无宝塔海外单机」的区别

| | 宝塔（本文） | Caddy 单机 |
|--|-------------|------------|
| 域名/证书 | 宝塔 | compose 内 Caddy |
| 推荐对象 | 国内面板用户 | 纯 SSH 海外 VPS |
| 脚本 | `deploy-baota.sh` | `deploy-single.sh` |

无宝塔时见仓库 README 附录，或 [`部署架构.md`](部署架构.md) §0。
