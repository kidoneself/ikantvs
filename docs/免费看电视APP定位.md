# 当「免费看电视 APP」用 · 产品定位说明

> 日期：2026-08-03  
> 状态：**现行可用定位**（不改代码也能这么讲、这么推）  
> 相关：[`产品决策-2026-06-30.md`](产品决策-2026-06-30.md)、[`项目进度.md`](项目进度.md) P3 域名网盘

---

## 1. 一句话

本站现在可以当成一个**免费看电视 / 追剧的入口**：搜片 → 点迅雷资源 → 用迅雷 APP 打开就能看。  
**不需要本站会员，也不需要迅雷会员。**

核心依据：站内的**迅雷盘资源本身免会员可看**（相对百度/夸克常见「非会员限速 / 看不了」），用户侧门槛最低。

---

## 2. 为什么能当免费 APP 用

| 点 | 说明 |
|---|---|
| **本站不收费** | 无前台用户、无会员/付费墙；游客即可浏览、搜索、取链 |
| **迅雷资源免会员** | 用户拿到迅雷分享后，用官方迅雷 APP 打开即可播放，不必买迅雷会员 |
| **磁力也可走迅雷** | 磁力链可经迅雷 JS-SDK / APP 拉起任务，同样落到「免费看」路径 |
| **域名可只开迅雷** | `naspt.vip` 策略为「仅磁力 + 迅雷」，整站体验就是免费看剧站，不被其它盘干扰 |

百度 / 夸克仍适合做转存推广变现；**「免费看电视」这条叙事，主推迅雷（+ 磁力）即可。**

---

## 3. 用户怎么用（对外话术）

1. 打开站点（免费看剧向：优先 `naspt.vip`；全盘版：`ikantvs.com` / `ik.naspt.vip`）。
2. 搜索想看的剧 / 电影 / 短剧。
3. 在结果里选 **迅雷**（或磁力）资源，点「获取链接」。
4. 用 **迅雷 APP** 打开分享 / 拉起下载任务。
5. 在 APP 里在线看或缓存后看——**全程不用本站登录、不用买会员。**

手机端：转存成功后可用弹窗里的二维码，迅雷 APP 扫一扫直达。

---

## 4. 和「网盘聚合站」的关系（对内）

| 角色 | 域名倾向 | 开盘 | 对外怎么说 |
|---|---|---|---|
| **免费看电视 APP** | `naspt.vip` | 仅迅雷 + 磁力 | 「免费追剧，迅雷打开就能看」 |
| **全盘资源站** | `ikantvs.com`、`ik.naspt.vip` | 全开 | 「多网盘聚合；要免费看优先选迅雷」 |

同一套 next 前后端，靠域名网盘配置切换形态，**不必再拆第二套产品。**

技术上仍是「信息流 + 转存取链」，并不是站内自建播放器；  
**用户感知上**可以等于「免费看电视 APP」——因为最后一步在迅雷 APP 完成，且免会员。

---

## 5. 运营注意

- **库存**：免费看剧体验取决于库里有足够多、足够新的迅雷（+ 磁力）有效链；追更 / 每日更新要优先保证迅雷落地。
- **失效**：死链会伤「能看」口碑；探活、失效治理对这条定位比「盘多」更重要。
- **话术边界**：说「免费看」指**不强制买本站/迅雷会员**；不承诺所有片源永久有效、不承诺画质/全集齐全。
- **变现不冲突**：全盘站继续走夸克/百度转存推广；免费看剧站用迅雷拉新、养习惯，两边可并存。

---

## 6. 配置 checklist（维持这条定位）

- [ ] `naspt.vip` 域名网盘保持 **仅迅雷 + 磁力**
- [ ] 前台迅雷 SDK / 推广位（`xunlei.sdk.enabled`、`xunlei.partner.custom`）按需开启，方便磁力一键进迅雷
- [ ] 内容侧持续灌迅雷链、监控追更落地夹可用
- [ ] 对外文案、投放落地页指向「免费看剧」域名，避免和全盘站混讲

> 产品形态不用重做；域名只开迅雷+磁力时，整站就是这个形态。
