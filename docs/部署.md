# 部署（宝塔 · 一份 compose）

只要 **一份** `docker-compose.yml`，业务镜像里已带建表 SQL，**不用**再下源码、不用 build。

## 宝塔页面操作

1. 安装 **Docker**
2. 打开仓库里的 [`deploy/docker-compose.yml`](https://github.com/kidoneself/ikantvs/blob/main/deploy/docker-compose.yml)，**全选复制**
3. 宝塔 → Docker → **编排** → 添加 → 粘贴 compose  
4. 同目录（或编排环境变量）配置密码，至少：

```env
MYSQL_ROOT_PASSWORD=自己设
DB_PASSWORD=自己设
JWT_SECRET=一长串随机至少32位
CORS_ALLOWED_ORIGINS=http://你的公网IP:3080
```

（也可把仓库 [`deploy/.env.example`](https://github.com/kidoneself/ikantvs/blob/main/deploy/.env.example) 存成同目录 `.env`）

5. 点 **启动**，等 pull 完成  
6. 防火墙放行 **3080**、**3081**

| 地址 | 用途 |
|------|------|
| `http://IP:3080` | 前台 |
| `http://IP:3081` | 后台（admin / admin123，改密） |

内存紧：在 compose 里删掉 `pansou` 服务，并设 `INGEST_PANSOU_ENABLED=false`。

## 有域名后

宝塔加站点 → SSL → 反代 `http://127.0.0.1:3080`；  
`CORS_ALLOWED_ORIGINS` 改成 `https://域名`，重启编排。

## 镜像

`ghcr.io/kidoneself/ikantvs`（GitHub Actions 在 `main` 自动构建）。  
Package 需为 **Public**。
