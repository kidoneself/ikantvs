# 部署（宝塔）

```bash
git clone https://github.com/kidoneself/ikantvs.git
cd ikantvs/deploy
./deploy.sh init
# 编辑 .env：密码、JWT_SECRET、CORS_ALLOWED_ORIGINS（你的 https 域名）
./deploy.sh up
```

| 端口 | 用途 |
|------|------|
| `127.0.0.1:3080` | 前台 |
| `127.0.0.1:3088` | API |
| `服务器IP:3081` | 后台 |

宝塔：

1. 装 **Docker**
2. **网站** → 加站点 → SSL
3. **反向代理** → `http://127.0.0.1:3080`
4. 站点配置加上：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:3088;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 120s;
    client_max_body_size 50m;
}
```

5. 前台 `https://域名`；后台 `http://IP:3081`（默认 admin / admin123，改密）

内存紧：`.env` 里 `ENABLE_PANSOU=false` 再 `./deploy.sh up`。
