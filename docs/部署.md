# 部署（宝塔 Docker Compose）

业务已打成 **一个镜像** `ghcr.io/kidoneself/ikantvs`（后端 + 前台 + 后台）。  
服务器上 **不用 build、不用拉源码**，只要 `deploy/` + `.env`。

## 步骤

1. 宝塔安装 **Docker**
2. 把仓库里的 `deploy/` 拷到服务器（或 `git clone` 后只用该目录），例如 `/www/ikantvs/deploy`
3. 配置环境变量：

```bash
cd /www/ikantvs/deploy
cp .env.example .env
# 改密码、JWT_SECRET；CORS 先写 http://服务器IP:3080
```

4. 启动（宝塔「编排」选本目录，或命令行）：

```bash
docker compose --env-file .env --profile pansou pull
docker compose --env-file .env --profile pansou up -d
# 或：./deploy.sh init && ./deploy.sh up
```

内存紧：`.env` 设 `ENABLE_PANSOU=false`，启动时去掉 `--profile pansou`。

5. 防火墙放行 **3080**、**3081**

| 地址 | 用途 |
|------|------|
| `http://服务器IP:3080` | 前台（含 `/api`） |
| `http://服务器IP:3081` | 后台（admin / admin123，改密） |

## 再配域名（可选）

宝塔加站点 → SSL → 反代 `http://127.0.0.1:3080`；  
`.env` 的 `CORS_ALLOWED_ORIGINS` 改成 `https://域名`，再 `docker compose up -d`。

## 目录

```
deploy/
  docker-compose.yml
  .env.example → .env
  init/          # 空库建表
  mysql/
```

镜像由 GitHub Actions 在 `main` 推送；也可本地构建：

```bash
# 仓库根目录
docker build -f deploy/Dockerfile.app -t ghcr.io/kidoneself/ikantvs:latest .
```
