# 使用说明

装好服务之后怎么用。部署步骤见 [部署.md](部署.md)。

默认入口：

| | 地址 |
|--|------|
| 前台 | `http://服务器IP:3080` |
| 后台 | `http://服务器IP:3081` |

---

## 1. 首次登录

1. 打开后台，用默认账号登录：`admin` / `admin123`
2. 进入 **系统 → 后台账号**，立刻修改密码（可再建运营账号）
3. 进入 **系统 → 系统设置**，按下面几节按需配置，点保存（多数项**立即生效**，不必重启）

角色简述：`admin` 可改系统与转存；`reviewer` 可管每日更新；`contributor` 可维护影视库。

---

## 2. 系统设置（常用）

路径：**系统 → 系统设置**（左侧按分组切换）。

### 网盘展示

控制前台详情 / 搜链页显示哪些网盘页签（夸克、百度、迅雷、磁力等）。关掉的类型前台不展示，采集侧也会少写该类链接。

### 网站公告

可开顶栏公告与弹窗，正文支持 HTML。适合发维护通知、加群引导。

### 资源采集

| 配置 | 说明 |
|------|------|
| 启用 pansou 采集 | 是否调用 pansou 搜网盘链 |
| pansou 接口地址 | 默认指向 Compose 内 `pansou` 服务 |
| 启用 Gying 采集 | 观影源；需同时填账号 |
| Gying 账号 | 格式 `邮箱:密码`，多个用逗号或换行分隔 |

`.env` 里的 `INGEST_*` 只在**第一次启动**写进库；以后改后台即可。

### 其它（可选）

- **迅雷转存**：填开放平台 `client_id` / `secret` 等，才好用迅雷 OAuth 落号  
- **运维通知**：飞书 / Webhook，默认关  

---

## 3. 片库从哪来

开源默认用 **夸克热榜** 自动灌库（环境变量 `QUARK_RANKING_ENABLED`，默认开）。

1. 首次启动后看业务容器日志，出现 `[quark-ranking] 同步完成` 即本轮结束（可能要几分钟）
2. 后台 **内容 → 影视库** 可搜索、编辑、手工新建；海报可本地上传或填 URL
3. 前台首页 / 榜单 / 搜索即可浏览

片库很少时：先等灌库跑完；仍空再查日志是否被风控或开关被关。

---

## 4. 前台搜链

用户在前台搜片名或点片进搜链页时，后端会按已启用的来源拉网盘链接：

1. **pansou**（默认开）：需 `ikantvs-pansou` 容器在跑  
2. **Gying**（默认关）：在「资源采集」打开并填账号后，下次搜索会懒登录  

内存紧、不要搜链时：按 [部署.md · 内存紧](部署.md#内存紧--不要-pansou) 关掉 pansou。此时仍可浏览片库与每日更新。

---

## 5. 每日更新

路径：**内容 → 每日更新**（需 reviewer 及以上）。

典型流程：

1. **新增 / 编辑**一条每日更新  
2. 绑定已有影视，或手填剧名  
3. 粘贴分享文案：可自动识别夸克 / 百度 / 迅雷链接与提取码  
4. 保存后前台「每日更新」展示；可配置巡检节奏做追更检测  

适合「今天更了哪几集、链贴在哪」的运营场景。

---

## 6. 转存（可选）

路径：**转存 → 网盘账号** / **转存任务**（需 admin）。

1. 在 **网盘账号** 添加夸克 / 百度 / 迅雷账号  
   - 夸克等：粘贴浏览器 Cookie  
   - 迅雷：需先在系统设置配好开放平台，再走授权  
2. 区分用途（如用户转存号 / 监控转存号），按界面提示操作  
3. **转存任务** 查看排队与结果  

未配账号时，前台转存入口不可用或会提示不支持——不影响浏览与搜链展示。

---

## 7. 其它运营能力

| 菜单 | 用途 |
|------|------|
| 运营 → 访问统计 | 匿名访问量概览 |
| 运营 → 敏感词 | 拦截或替换不当词 |
| 运营 → 加群活码 | 上传群码图，前台/公告可引导加群 |
| 运营 → 文档采集 | 监控在线文档里的分享链并入库 |
| 运营 → IP 防护 | IP 黑名单 / 限流相关 |

---

## 8. 前台用户侧

无需注册。常见路径：

- 首页浏览 / 榜单  
- 搜索片名 → 进搜链页选网盘打开或转存  
- 每日更新列表看今日资源  

顶栏可展示公告；「加群」类入口依赖你在后台配的活码 / 公告 HTML。

---

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| 后台登不上 | 确认 `3081` 已放行；账号密码是否已改过 |
| 前台空白或接口失败 | `.env` 中 `CORS_ALLOWED_ORIGINS` 必须与浏览器地址一致（协议、域名、端口） |
| 片库几乎是空的 | 等夸克灌库；`docker compose logs -f app` 看 `[quark-ranking]` |
| 搜不到网盘链 | pansou 容器是否在跑；系统设置里 pansou 是否启用；可选再开 Gying |
| Gying 登录失败 | 账号格式是否为 `user:pass`；站点是否要求验证 / 改密 |
| 改了设置没变化 | 确认已点保存；硬刷新浏览器；Gying 账号变更后下次搜索才会重新登录 |
| 转存失败 | 网盘账号 Cookie/授权是否过期；迅雷是否配齐 client 信息 |

更多部署向排错见 [部署.md · 常见问题](部署.md#常见问题)。

---

## 10. 建议的日常节奏

1. 早上看 **每日更新** 是否要贴新链  
2. 偶尔扫 **影视库** 补漏、改海报  
3. 搜链异常时先看 pansou / Gying 开关与容器状态  
4. 转存号定期检查是否掉线（**网盘账号** 页）
