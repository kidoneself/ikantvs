## 1. 用户体系

- **无前台用户**：游客浏览/搜索/看链，无需登录。
- **`user` 表仅运营账号**：录入员 / 审核员 / 管理员，仅供后台登录。
- 已删除：`user_favorite`、注册/邀请码、会员字段、卡密计费表。

## 2. 商业化

- **不做会员订阅 / 卡密 / 付费墙**。
- 变现走**老站同款**：网盘转存 + 推广分成（夸克/百度为主），不靠向用户收 9.9。
- 详情页点击链 → 经平台**转存**（`/api/transfer/execute` 一类能力，从老项目 `jyinshi` 移植），对用户免费。

## 3. 埋点（analytics）

- **纯匿名**：`content_event` 不含 `user_id`。
- 保留：搜索、详情浏览、网盘链点击、卡片点击。
- 已移除：收藏、付费墙命中（无用户体系后无意义）。

## 4. 部署

- 生产：`docker-compose.prod.yml` = MySQL + Redis + backend + web + admin + Caddy（独立 VPS，不依赖老项目）。
- 日常发版：`deploy/deploy-prod.sh`（默认只重建前台 web）。

## 5. 待做（按优先级）

详见 [`项目进度.md`](项目进度.md) 完整清单。摘要：

1. **transfer 域**：从老站移植转存（百度/夸克/迅雷），详情页「获取链接」交互对齐老站。
2. 后台链接管理 + 审核台（内容运营闭环）。
3. PanSou 聚合搜索（扩大候选链来源）。
