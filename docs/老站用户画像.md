# 老站用户画像（基于 jyinshi_db 行为数据）

> 数据来源：老库 `search_log`、`user_transfer_action`、`search_cache` 等（**无前台注册用户表**，按 IP + 行为统计）。  
> 统计窗口：**近 30 天**（相对查询日 2026-06-29）；收入结构见 `daily_operation_data`。  
> 用途：新站定价、付费墙、产品优先级（manual 补链、移动端、夸克优先）。

---

## 一句话画像

**手机上的追剧/找片用户**：晚上搜、搜完就转存，**夸克为主**，目标明确；**多数来一两次就走**，少数重度用户贡献大部分转存与付费潜力。

---

## 1. 规模

| 指标 | 数值 |
|------|------|
| 月搜索独立 IP | **~4.3 万** |
| 月有转存/要链行为 IP | **~3.1 万** |
| 既搜又转 IP | **~3.09 万**（几乎「要链」的人都会先搜） |
| 月搜索次数 | **~19.9 万**（人均 **4.6 次/IP**） |
| 历史转存行为 | **~81 万次**，**~15.9 万** 历史独立 IP |

**说明**：老站以匿名访问为主，没有 C 端账号体系；新站若收费需 **登录 + 会员**，会多一道转化门槛。

## 2. 活跃度（二八明显）

| 月搜索次数/IP | 占比 | 类型 |
|---------------|------|------|
| 只搜 **1 次** | **35.8%** | 路过 / 试一次 |
| **2～3 次** | **30.6%** | 轻度 |
| **4～10 次** | **25.1%** | 偶尔用 |
| **11～30 次** | **7.3%** | 常客 |
| **31+ 次** | **~1.2%** | 核心铁粉 |

- 人均搜索 **4.6 次/IP**；单 IP 最高 **5039 次/月**（异常/脚本需排除，但说明有极端重度用户）。
- 转存侧：**又搜又转** 是主路径；**只转不搜** 极少。

**付费潜力（粗估）**：

| 分层 | 约 IP 数/月 | 特征 | 运营策略 |
|------|-------------|------|----------|
| A 路过 | ~1.5 万 | 只搜 1 次 | 免费即可，不指望付费 |
| B 偶尔 | ~1.3 万 | 月搜 2～10 次 | 转链 + 限量链 |
| C 常客 | ~3500 | 月搜 11+ 次 | **9.9 主战场** |
| D 核心 | ~500 | 月搜 31+ 次 | 年卡、直开全链 |

保守 **300～500 付费用户** ≈ C+D 中 **10%～15%** 转化。

- **高峰：18～22 点**（21 点最多）

典型场景：**下班后手机搜剧 → 转存/保存**。

## 9. 收入与用户行为的关系

- 老站 **~6000～8000/月** 主要来自 **网盘会员推广分成**，不是 relay 转存费本身。
- 用户感知是 **免费站 + 点转存**；钱在「用户开夸克/百度会员」侧被动结算。
- 新站若改 **9.9 直接向用户收费**，难度高于延续推广分成；宜 **订阅 + 转链留推广** 双线（见 [`产品备忘-免费转链与会员直开.md`](产品备忘-免费转链与会员直开.md)）。

---

## 10. 对新站的产品结论

1. **工具型用户**，不是「为网站付费」型 → 卖 **直开 + 全链 + 热门核验**，比抽象会员好卖。  
2. **82% 移动端** → 交互与付费流程移动优先。  
3. **夸克 6 成行为 + 7 成收入** → 夸克体验第一优先级。  
4. **66% 月搜 ≤3 次** → 勿对 4.3 万 IP 全量预期付费；聚焦 **~3500 常客 IP**。  
5. **剧集 + 热榜** → manual 运营投 **~77～100 部** 即可，非 74 万链。

## 画像卡片（PRD 用）

> **主力用户**：移动端用户，夸克/微信内晚上搜剧，搜完要链；约 **8%** 为月搜 11 次以上的常客，是 **9.9/年卡** 目标人群。  
> **非目标**：极少 PC；很少为「支持站点」付费，只为 **省一步、链更干净、秒开** 付费。

## 数据查询说明

```sql
-- 月搜索 IP
SELECT COUNT(DISTINCT ip_address) FROM search_log
WHERE search_time >= DATE_SUB(NOW(), INTERVAL 30 DAY);

-- 月转存 IP
SELECT COUNT(DISTINCT ip_address) FROM user_transfer_action
WHERE action_time >= DATE_SUB(NOW(), INTERVAL 30 DAY);
```

老库只读，迁移/分析勿写生产。
